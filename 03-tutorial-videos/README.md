## Bonus Video (Part 6)

Accompanies `../08-bonus/file-splitting-plan.md`. Demonstrates the BEGIN_FILE comment approach to splitting a single TextGen output into multiple files using external scripts — the workaround for MPS's one-root-concept = one-output-file limitation.
